// workflow

From your terminal to production. One command.

Link the project. Push the branch. Acme handles the build, the URL, the cache headers, the rollback plan. You handle the merge.

  • Atomic deploys with one-click instant rollback
  • Preview environments for every pull request
  • Built-in CI with smart caching across branches
  • Bring-your-own-domain with auto-renewing TLS
~/projects/web-app — zsh 
# link the repo, once
$ acme link

# push to preview
$ git push origin feat/checkout-v2
  → building "feat-checkout-v2"...
  → deployed in 12.4s
  → https://feat-checkout-v2.acme.app

# promote to production
$ acme promote feat-checkout-v2
  ✓ live on acme.app
  ✓ cache invalidated (300 POPs)
